# JavaScript Mini Bootcamp

This repository contains the files used during a one-class JavaScript mini bootcamp. The goal is to review the core concepts of JavaScript before starting application development with Firebase.

## 📂 Project Structure

```
.
├── 1 - variaveis.js
├── 2 - desestruturacao.js
├── 3 - spread.js
├── 4 - if.js
├── 5 - function.js
├── 6 - arrowFunction.js
├── 7 - importExport.js
└── 8 - mapFilter.js
```

## 📚 Topics Covered

- Variables
- Destructuring
- Spread Operator
- Conditional Statements (`if`)
- Functions
- Arrow Functions
- Import & Export
- `map()` and `filter()`

---

Created for JavaScript fundamentals review before working with Firebase.
